For facilitators

A short summary of how the Let's Code session runs, plus every file you need. This is the plan for a 70-minute build session with Standard 5 and 6 pupils.

Time plan

These times are a suggestion. Change them to suit your group. If you run late, shorten Step 5.

StepPupils doMinutes
0Meet Scratch8
1Move the Basket8
2Make the Apple fall10
3Catch the Apple and score14
4AKeep the apples coming (forever)6
4BAdd the Bomb and change the speed10
5Add lives (stretch step)10
Spare time4

How every step runs

  1. Explain. Say the goal of the step in one line.
  2. Show. Put the picture from the Build page on the projector, or print it.
  3. Build. Pupils copy the blocks into Scratch.
  4. Test. Pupils press the green flag. If it works, move on. If not, compare their screen with the picture: first the sprite, then the numbers, then the dropdowns.
  5. Extra time? Give a group that is ahead a Bug Card. The step always comes before the Bug Card.

Good to know

  • Pupils should save often: File, then Save to your computer. If work is lost, use File, then Load from your computer.
  • A group that is behind can load the saved file of the step before. Step 3 stuck? Load catch-step2.
  • The speed numbers change between steps. That is fine. Speed is a setting. Let pupils choose what feels right, and ask them why.
  • The starter file has no Score or Lives variables. Pupils make them at Step 3 and Step 5.
  • Explain the or block like this: stop falling when the Apple touches the Basket, or when it reaches the bottom.

Bug Card answers

Show the answers (facilitators only)
  • Card 1, The Apple That Flies Away. change y by has a positive number. Change it to a negative number, for example -7.
  • Card 2, Only One Apple. There is no forever block. Put the falling blocks inside forever.
  • Card 3, The Score Starts Too High. set Score to 0 is missing under the green flag.
  • Card 4, The Game That Never Ends. set Lives to 3 is missing. Extra challenge: change Lives = 0 to Lives < 1.
  • Card 5, The Basket Will Not Move. The arrow key script is in the Apple sprite. Drag it onto the Basket sprite.
