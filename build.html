Build it yourself

You will build Catch and Avoid in six short steps. Each step adds one new idea. Do the steps in order.

Get started

  1. Open Scratch. Use Scratch Desktop (free, from scratch.mit.edu/download) or the online editor. You do not need an account.
  2. Download the starter file. Download catch-starter.sb3
  3. In Scratch, click File, then Load from your computer. Choose catch-starter.
  4. Save often. Click File, then Save to your computer. If your work is lost, open the last file you saved.

The Scratch blocks stay in English. This is on purpose, so the pictures on this page match what you see.

Meet Scratch

Look at the Scratch screen. You will use these four parts all the time.

Check: click each sprite. You see an empty Code area, because we have not built anything yet.

  • 1Stage: where the game plays.
  • 2Sprite list: the Basket, the Apple and the Bomb.
  • 3Code area: where you drag blocks to build code.
  • 4Green flag: starts the game.
Stuck? Download the saved file for this step: catch-starter.sb3 catch-step0.sb3
1

Move the Basket

Click the Basket sprite in the sprite list. Build these three scripts. A script starts with a yellow block that waits for something to happen.

Check: press the left and right arrow keys. The Basket moves. Press the green flag. The Basket goes back to the bottom middle.

Stuck? Download the saved file for this step: catch-step1.sb3
2

Make the Apple fall

Click the Apple sprite. Build this script. The repeat until block keeps the Apple falling until its y position is below -170, the bottom of the Stage.

Check: press the green flag. The Apple starts at the top in a different place each time, then falls and stops at the bottom.

Tip: a bigger minus number after change y by makes the Apple fall faster.

Stuck? Download the saved file for this step: catch-step2.sb3
3

Catch the Apple and score

First, make a variable called Score. A variable is a box that remembers a number.

Then build these scripts. The Basket sets the Score to 0 at the start. The Apple adds 1 to the Score when it touches the Basket. The arrow key scripts now use 20. You can choose your own number.

Tip: in the touching block, click the dropdown and choose Basket. At first it says mouse-pointer.

The green or block means: stop falling when the Apple touches the Basket or when it reaches the bottom.

Check: catch an Apple. The Score goes up by 1. Miss an Apple. The Score stays the same.

Stuck? Download the saved file for this step: catch-step3.sb3
4

Keep going and add the Bomb

Part A: more apples

Put the Apple's blocks inside a forever block. Now a new Apple starts every time the last one lands.

Check: apples keep falling, one after another.

Part B: the Bomb and the speed

Now the Bomb. Catching the Bomb ends the game. Tip: drag the Apple script onto the Bomb sprite to copy it. Then change the blocks inside the if: remove change Score by 1, and add say Game Over! for 2 seconds and stop all.

The Apple now falls a little faster (-8). Speed is your choice: try other numbers.

Check: the Bomb falls too. Catch it and the game stops with Game Over!

Stuck? Download the saved file for this step: catch-step4a.sb3 (Part A) catch-step4b.sb3 (Part B)
5

Add lives

Make a second variable called Lives.

The Basket starts with 3 lives. When an Apple is missed, you lose 1 life. At 0 lives, the game ends.

Check: miss an Apple. Lives goes down by 1. At 0 the game says Game Over!

Stuck? Download the saved file for this step: catch-step5.sb3 catch-final.sb3 (finished game)

Well done!

Your game is finished. Now try the Bug Cards, or change the game: new speeds, new ideas.
